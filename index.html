시작하려면 Gemini API 키가 하나 필요합니다

받아쓰기와 회의록 정리는 본인 Google 계정의 Gemini로 처리합니다. 처음 한 번만 하면 되고, 무료로 받을 수 있습니다.

  1. Google AI Studio 키 페이지를 엽니다 aistudio.google.com/apikey 에서 Google 계정으로 로그인합니다. 처음이면 약관 동의 화면이 나옵니다.
  2. API 키 만들기 버튼을 누릅니다 프로젝트를 고르라고 하면 기본으로 나오는 프로젝트를 그대로 쓰거나 새로 만듭니다. 결제 정보는 넣지 않아도 됩니다.
  3. 만들어진 키를 복사해 아래에 붙여넣습니다 AIza… 로 시작하는 문자열입니다. 키는 이 브라우저에만 저장되고, 녹음과 함께 Google로만 보내집니다.
공용 PC라면 다 쓴 뒤 상단의 키 표시를 눌러 지워주세요.

무료로 얼마나 쓸 수 있나요

요청 2번30분 이하 회의 1건에 드는 요청 (받아쓰기 1번 + 회의록 정리 1번)
30분 단위받아쓰기 한 번에 맡기는 길이. 1시간 회의는 받아쓰기 2번
오후 4~5시하루 사용량이 다시 채워지는 시각 (미국 서부 자정)

받아쓰기는 Google의 받아쓰기 전용 모델로, 회의록 정리는 Gemini Flash-Lite(무료 하루 약 500번)로 합니다. Flash-Lite 한도를 다 쓰면 Flash로 정리합니다. 한도는 계정마다 다르고 수시로 바뀌니 AI Studio 사용량 화면에서 확인하세요.

민감한 회의에는 쓰지 마세요. 무료 키로 보낸 녹음과 결과는 Google이 서비스 개선에 쓸 수 있고, 사람이 검토할 수도 있습니다. 인사·계약·보안 관련 회의는 녹음을 올리지 마세요.
