# 녹음 회의록

휴대폰 녹음 파일을 올리면 화자별 대화록과 회의록(회의 주제, 논의 과정, 결론, Task)을 만들어 주는 웹페이지입니다.
서버 없이 브라우저에서 사용자 본인의 Gemini API 키로 Google에 직접 요청합니다.

**사용하기: https://gyugyu98.github.io/meeting-minutes/** (Gemini API 키만 있으면 됩니다)

## 내 PC에서 실행

`index.html`을 더블클릭해 브라우저(Chrome, Edge)로 엽니다. 서버는 필요 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 5단계 (시작하기, 녹음 올리기, 처리 중, 화자 이름, 회의록) |
| `style.css` | 화면 스타일 (라이트/다크) |
| `gemini.js` | Gemini API 호출: 모델 선택, 파일 업로드, 받아쓰기 전용 모델 호출, JSON 생성 요청, 재시도 |
| `app.js` | 화면 동작: 녹음 자르기, 받아쓰기, 회의록 정리, 화자 이름 바꾸기, 양식 관리, 복사 |
| `templates.js` | 회의록 양식: 저장, 파일에서 읽기(md·txt·docx·hwp·hwpx), 공유 링크, 마크다운 ↔ 화면 변환 |
| `vendor/` | 양식 파일을 읽을 때만 불러오는 라이브러리: mammoth 1.12.0(docx), JSZip 3.10.1(hwpx), hwp.js 0.0.3을 브라우저용으로 묶은 파일(hwp) |

## 처리 방식

| 단계 | 모델 | 요청 수 |
|---|---|---|
| 받아쓰기 | `gemini-3.5-transcribe` (받아쓰기 전용, 화자 구분 내장) | 30분마다 1번 |
| 회의록 정리 | Flash-Lite (`gemini-3.5-flash-lite` 등) → 하루 한도에 걸리면 Flash | 회의당 1번 |

- 받아쓰기 전용 모델은 화자 구분을 켜면 요청 하나에 30분까지 받습니다. 30분 이하 녹음은 원본 파일을 그대로 올리고, 더 길면 브라우저에서 녹음을 풀어(16kHz) 29분 이하 조각의 wav로 잘라 올립니다(조각 2개씩 동시에).
- 받아쓰기 요청은 `audioTranscriptionConfig: { languageCodes: ['ko-KR'], diarization: true }`입니다. 단어별 시각(`wordTimestamp`)은 정확도를 떨어뜨린다고 문서에 나와 있어 켜지 않습니다. 응답에 시각이 없으면 글자 수 비율로 어림잡아 `≈`를 붙여 보여줍니다.
- 조각마다 화자 번호가 따로 매겨지므로, 회의록 정리 요청에서 대화 흐름을 보고 회의 전체 번호로 맞추게 합니다(`speakerMap`). 짝을 못 찾은 화자는 새 번호를 받고, 화자 이름 단계에서 같은 이름을 넣어 합칠 수 있습니다.
- 받아쓰기 전용 모델을 쓸 수 없으면(키에 열리지 않음, 하루 한도) Flash-Lite에게 지시문으로 받아쓰게 합니다.
- 받아쓰기가 끝나면 올린 녹음 파일을 Google에서 바로 지웁니다.
- 회의록 정리는 추론을 낮게 설정하고 스트리밍으로 받습니다. 정리 수준을 바꿔 다시 정리할 때는 대화록 텍스트만 보내므로 요청 1번만 씁니다.
- 분당 한도에 걸리면 Google이 응답에 알려준 시간만큼 기다렸다 다시 시도합니다. 하루 한도에 걸리면 멈추고, 창을 닫지 않으면 이어서 다시 시도할 수 있습니다.
- 처리 화면의 "처리 시간 측정"에 요청마다 걸린 시간과 입력·추론·출력 토큰 수를 표시합니다(브라우저 콘솔에도 기록). 받아쓰기 응답의 앞부분도 콘솔에 남깁니다.

## 회의록 양식

- 녹음 올리기 화면의 "회의록 양식"에서 기본 양식(주제·논의·결론·Task) 대신 내 양식을 고를 수 있습니다. 양식은 붙여넣거나 md·txt·docx·hwp·hwpx 파일에서 불러옵니다. 양식은 각자 브라우저에 저장됩니다.
- 내 양식을 고르면 회의록 정리 요청에 양식을 함께 보내, 제목·항목 순서와 표·목록·체크박스 모양을 지킨 마크다운으로 받습니다. 괄호 안 설명과 자리 표시는 작성 지침으로 씁니다. 결과는 양식 모양 그대로 그려져 그 자리에서 고칠 수 있습니다.
- [공유 링크 복사]는 양식을 압축해 주소 뒤(`#tpl=…`)에 담은 링크를 만듭니다. 받은 사람이 열면 양식이 자동으로 추가됩니다. 서버에는 저장되지 않습니다.
- hwp는 문단 글자와 표만 읽습니다(글자 모양·그림은 빠짐). 읽기가 안 되는 파일은 내용을 복사해 붙여넣으면 됩니다.
