# 녹음 회의록

휴대폰으로 녹음한 회의를 올리면 **화자별 대화록**과 **회의록**(주제 · 논의 과정 · 결론 · Task)을 만들어 줍니다.
서버 없이 브라우저에서 내 Gemini API 키로 동작합니다.

👉 **https://gyugyu98.github.io/meeting-minutes/**

---

## 사용 방법

1. **API 키 넣기** — 처음 한 번, 시작 화면 안내대로 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 키를 받아 붙여넣습니다.
2. **녹음 올리기** — m4a · mp3 · wav 파일을 고르고 양식 · 정리 수준 · 정리 스타일을 고릅니다.
3. **화자 이름 정하기** — 대표 발언을 보고 화자1, 화자2에 이름을 붙입니다.
4. **회의록 받기** — 화면에서 바로 고치고, 노션용 복사 또는 파일(.hwpx · .docx · .md)로 받습니다.

> 22분 녹음 기준 전체 처리 약 10초. 회의 1건에 Gemini 요청 2번(받아쓰기 1 + 정리 1)이 듭니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| **화자 구분 받아쓰기** | 받아쓰기 전용 모델이 사람별로 나눠 적습니다. 1시간 이상 녹음도 됩니다. |
| **정리 수준** | 간단 · 보통 · 자세히 — 회의 길이에 맞춰 분량이 늘어납니다. |
| **정리 스타일** | 발언자별 · 안건별 요약 · 흐름순 · **직접 작성**(내가 쓴 정리 방식) |
| **내 회의록 양식** | 회사 양식(hwpx · docx · hwp · md)을 올리면 그 항목대로 정리합니다. |
| **회사 양식에 채우기** | hwpx · docx 양식은 원본 파일에 글자만 채워 같은 형식으로 돌려줍니다. 로고 · 표 · 글꼴 그대로. |
| **다시 정리** | 결과 화면에서 양식 · 수준 · 스타일만 바꿔 다시 만듭니다. 녹음을 다시 올리지 않습니다. |

문장은 회의록 형식대로 "~함 · ~음 · 명사"로 끝맺고, Task는 노션에 붙이면 할 일 목록이 되는 체크박스로 나옵니다.

## 양식과 내려받는 파일

| 올린 양식 | 받을 수 있는 파일 |
|---|---|
| **.hwpx** | 회사 양식에 채우기(.hwpx) · 기본 서식 워드 · 마크다운 |
| **.docx** | 회사 양식에 채우기(.docx) · 기본 서식 한글 · 마크다운 |
| **.hwp** | 기본 서식 파일만 — 한글에서 **[다른 이름으로 저장 → HWPX]** 후 올리면 서식 그대로 받을 수 있습니다 |
| 붙여넣기 · 기본 양식 | 기본 서식 워드 · 한글 · 마크다운 |

> 이미 작성한 회의록을 양식으로 올려도 됩니다. 안의 내용은 형식 참고로만 쓰고, 작성자 · 부서 칸은 바꾸지 않습니다.

## 알아두기

- **민감한 회의에는 쓰지 마세요.** 무료 키로 보낸 녹음 · 결과는 Google이 서비스 개선에 쓸 수 있습니다.
- **화자 구분은 모델 성능에 달려 있습니다.** 3명 이상은 가끔 섞입니다. 같은 사람이 둘로 나뉘면 같은 이름을 넣어 합치세요.
- **한글 결과물은 .hwpx입니다.** 브라우저에서 .hwp를 쓸 수 없어서입니다. 필요하면 한글에서 .hwp로 저장하세요.
- **무료 사용량**은 계정마다 다릅니다. [AI Studio 사용량 화면](https://aistudio.google.com/rate-limit)에서 확인하세요. 다 쓰면 한국 시간 오후 4~5시에 다시 채워집니다.

변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 개발자용

### 내 PC에서 실행

`index.html`을 더블클릭해 Chrome · Edge로 엽니다. 빌드 · 서버 필요 없음.

### 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` · `style.css` | 화면 5단계(시작 · 녹음 올리기 · 처리 · 화자 이름 · 회의록), 라이트/다크 |
| `gemini.js` | Gemini API: 모델 선택, 파일 업로드, 받아쓰기, JSON 생성(스트리밍), 재시도 |
| `app.js` | 처리 흐름, 회의록 정리 지시문, 화면 · 복사 · 내려받기, 양식 관리 |
| `templates.js` | 양식 읽기(md · txt · docx · hwp · hwpx), 양식 파일에 채우기, 기본 서식 파일 만들기 |
| `vendor/` | JSZip 3.10.1, hwp-convert 1.12.0(일반 스크립트로 다시 묶음) — 필요할 때만 불러옴 |

<details>
<summary><b>처리 방식</b></summary>

| 단계 | 모델 | 요청 수 |
|---|---|---|
| 받아쓰기 | `gemini-3.5-transcribe` (화자 구분 내장) | 30분마다 1번 |
| 회의록 정리 | Flash-Lite → 하루 한도 시 Flash | 회의당 1번 |
| 회사 양식에 채우기 | Flash-Lite | 받을 때 1번 |

- 받아쓰기: `audioTranscriptionConfig: { languageCodes: ['ko-KR'], diarization: true }`. 화자 구분을 켜면 요청당 30분까지라, 더 긴 녹음은 브라우저에서 16kHz로 풀어 29분 이하 wav 조각으로 잘라 올립니다(2개씩 동시). 받아쓴 뒤 올린 파일은 바로 지웁니다.
- 조각마다 따로 매겨진 화자 번호는 회의록 정리 요청에서 `speakerMap`으로 맞춥니다.
- 단어별 시각은 정확도를 떨어뜨려 켜지 않고, 시각이 없으면 글자 수 비율로 어림합니다(`≈`).
- 받아쓰기 전용 모델을 못 쓰는 키는 Flash-Lite에게 지시문으로 받아쓰게 합니다.
- 분당 한도는 응답의 `retryDelay`만큼 기다렸다 재시도, 하루 한도는 멈추고 창을 닫지 않으면 이어서 다시 시도할 수 있습니다.
- 처리 화면의 "처리 시간 측정"과 브라우저 콘솔에 요청별 시간 · 토큰 수가 남습니다.

</details>

<details>
<summary><b>회사 양식에 채우기</b></summary>

- 양식 파일의 표 칸(C번호)과 문단(P번호, 글자 모양 조각 포함) 목록 + 화면의 최종 회의록을 Gemini에게 보내 **어느 칸에 어떤 문단을, 어느 예시 문단 모양으로** 넣을지 계획을 받습니다.
- 계획대로 예시 문단을 복제해 글자만 바꾸므로 글자 · 문단 모양, 칸 병합, 로고가 그대로 남습니다.
- 코드에서 막는 것: 작성자 · 부서 · 비고 · 결재 칸 수정, 한 문단에 몰린 목록 항목(나눔), 마크다운 기호(뺌).
- hwpx: mimetype을 맨 앞에 압축 없이 두고, 바꾼 문단의 `linesegarray`를 지워 한글이 다시 배치하게 합니다. 문단 id는 문서 전체에서 겹치지 않게 매깁니다.
- docx: 바꾼 문단의 paraId 등은 빼고, 한글이 내보낸 docx의 내용 칸 행 최소 높이(한 쪽 가득)를 풀어 워드에서 쪽이 넘치지 않게 합니다.
- hwp는 hwpx 변환 과정에서 로고 · 머리 표가 깨져(한글로 PDF를 뽑아 확인) 글자 구성만 읽습니다.
- 서식표 양식은 "- 일시: 값" 머리 항목과 내용 구성(## 제목, ### 발표자, 굵은 안건, 하위 세부)으로 읽어 화면 회의록에 씁니다.

</details>
